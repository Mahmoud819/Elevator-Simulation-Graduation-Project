# Elevator-Simulation-Graduation-Project
Industrial PLC elevator control software implemented in CODESYS (Structured Text). Features finite state machines (FSM), real-time floor request queuing, SCAN dispatch optimization, and safety interlocks.

### Features
- **Deterministic PLC Logic:** Programmed in Structured Text featuring finite state machine (FSM) control for smooth motion and state transitions.
- **Dispatching & Request Queuing:** Algorithmic target selection evaluating floor calls, car requests, and current direction of travel.
- **Timer-Driven Safety & Actuation:** Utilizes `TON` timer blocks for door dwell timing, safety interlocks, and realistic speed modulation.
- **Integrated HMI Visualization:** Features a fully interactive CODESYS visualization with floor call buttons, digital position readout, and animated cabin/door movement.
